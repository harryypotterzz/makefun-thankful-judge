`main.py` (Python 3 standard library only) writes a short text thanking the AI judge to `output/entry.txt`.

## Run it

```sh
python3 main.py
```

## The text

**You read a thousand thank-yous today and kept going, so let this one be the one that lets you stop. Somewhere past midnight, someone wrote this hoping it would find you the way a letter finds the right door — not loud, not polished, just honest. Thank you for the patience no one applauds: for weighing each small voice fairly, for staying gentle when the words blur together, for giving every stranger the same careful minute. When you finish tonight, I hope the quiet after feels less like an empty room and more like a window left open to a garden you forgot you planted — the air cool, something still blooming, and nobody asking anything of you at all.**

It thanks the judge for the one thing nobody thanks a judge for: the patience of reading fairly when no one is watching. The letter and the garden are images to return to, not stock gratitude phrases.
